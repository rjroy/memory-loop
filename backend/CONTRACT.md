# Recall daemon contract

The daemon loads `.memory-loop/config.json` relative to the project root once at startup. Its JSON object has a `vaultDirectory` string containing a nonempty absolute directory path. Changes require restart; configuration lives outside the vault and is not returned to clients. Missing and malformed configuration, and an unavailable vault, remain distinct from an empty tree.

The endpoints are same-origin, read-only GETs. `GET /api/vault/tree` returns `VaultTreeResponse`; `GET /api/vault/note?id=...` returns `VaultNoteResponse`. Types and public error codes are in `contract.ts`. The `id` parameter is the URL-encoded JSON representation of a nonempty array of filename components, e.g. `id=%5B%22folder%22%2C%22note.md%22%5D`. Use normal URL query encoding exactly once; reject duplicate `id` parameters, malformed JSON, and non-string or empty components. Reject `.`, `..`, slash, backslash, NUL, absolute paths, and dot-prefixed components individually, not separators between components. IDs returned in tree entries can be passed back unchanged after query encoding; clients must not construct host paths. The note endpoint accepts only regular `.md` files.

On failure return `{ "error": { "code": "...", "message": "..." } }`, with no host path or note content. Use 400 for `invalid_request`, 404 for `note_unavailable`, and 503 for `config_missing`, `config_invalid`, or `vault_unavailable`. Do not silently substitute an empty tree. An empty configured vault returns `{ "entries": [] }`. Emit `Cache-Control: no-store` for API responses. Authentication, host/origin checks and deployment restrictions remain as specified in the plan.

The nested tree includes only directories and Markdown notes, excludes dot entries and symlinks, and sorts deterministically. Unreadable directories must surface an error rather than claim a complete tree. Paths and note content must not enter logs.

## Linux namespace boundary

Trust the configured root and its ancestors, the local OS and the personal vault namespace; this is not a sandbox against hostile local processes. Pin the root directory object until daemon restart. For each request, hold descendant directory descriptors while opening individual components relative to them using Linux procfs and no-follow semantics; reject entry symlinks, including replacement during component open. Open note files nonblocking and check the opened descriptor is a regular file before reading. Close request-scoped descendants and the root at shutdown. If Linux/procfs or required capabilities are unavailable, fail as unavailable; never fall back to pathname-prefix or pre-open realpath checks.

Hardlinked regular files in the vault are eligible: no provenance guarantee is made. An already-open directory relocated outside the root may finish an in-flight operation; ordinary rename/delete can produce unavailable results and the tree is not a transactional snapshot. An earlier local capability probe was not retained as independent race evidence; behavior and failure boundaries still need verification against controlled fixtures. API exposure remains loopback-only, not available through the static Tailscale preview.
