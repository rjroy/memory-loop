### State and action contract

| State / action | Visible result and retained state |
|---|---|
| Reading → Edit | Preserve current reading position and initialize source from the exact loaded note plus its daemon revision. | Editing, unchanged | Save remains visible but unavailable; Cancel returns to reading without confirmation. Dirty means exact string inequality against the saved base, including whitespace. Returning to the base text clears dirty. Empty Markdown is valid. |
| Editing, dirty | Show Unsaved changes; enable Save. No write until explicit Save or its keyboard equivalent. Native editing, undo, selection and copy remain intact. |
| Save requested | Capture the exact file ID, source, base revision and draft generation. Button reads **Saving…**, prevents duplicate requests, and exposes busy state. Textarea stays editable. Browser unload protection remains active while a save is unresolved. |
| Save confirmed, draft unchanged since request | Render the confirmed saved source with the existing Markdown renderer, return titlebar to Edit, announce **Note saved.**, restore the prior reading position clamped to the new body, and focus Edit when focus still belongs to the completed action/editor. Do not clear an error or claim success before confirmation. |
| Save confirmed, newer typing exists | Stay in edit mode with all newer text, cursor and source scroll intact. Advance the saved base/revision only to the acknowledged source. Show Unsaved changes; announce **Saved. Newer changes are not saved yet.** No second automatic save. |
| Known save rejection | Stay in edit mode. **Couldn't save this note.** — **Your draft is still here. Try saving again.** Keep text, selection, source scroll and original revision; Save becomes available for an explicit retry when the failure is retryable. | External-change conflict | **This note has changed since you opened it.** — **Your draft is still here.
