### State and action contract

| State / action | Visible result and retained state |
|---|---|
| Reading → Edit | Preserve current reading position and initialize source from the exact loaded note plus its daemon revision. Show Cancel/Save and focus the textarea without opening the phone keyboard on mere file selection. Start at source top; do not pretend rendered and source offsets correspond. |
| Editing, unchanged | Save remains visible but unavailable; Cancel returns to reading without confirmation. Dirty means exact string inequality against the saved base, including whitespace. Returning to the base text clears dirty. Empty Markdown is valid. |
| Editing, dirty | Show Unsaved changes; enable Save. No write until explicit Save or its keyboard equivalent. Native editing, undo, selection and copy remain intact. |
| Save requested | Capture the exact file ID, source, base revision and draft generation. Button reads **Saving…**, prevents duplicate requests, and exposes busy state. Textarea stays editable. Cancel and same-view departures wait for the outcome; show **Saving… Please wait before leaving.** if departure is attempted. Do not imply Cancel can undo an accepted write. Browser unload protection remains active while a save is unresolved. |
| Save confirmed, draft unchanged since request | Render the confirmed saved source with the existing Markdown renderer, return titlebar to Edit, announce **Note saved.**, restore the prior reading position clamped to the new body, and focus Edit when focus still belongs to the completed action/editor. Do not clear an error or claim success before confirmation. |
| Save confirmed, newer typing exists | Stay in edit mode with all newer text, cursor and source scroll intact. Advance the saved base/revision only to the acknowledged source. Show Unsaved changes; announce **Saved. Newer changes are not saved yet.** No second automatic save. |
| Known save rejection | Stay in edit mode. **Couldn't save this note.** — **Your draft is still here. Try saving again.** Keep text, selection, source scroll and original revision; Save becomes available for an explicit retry when the failure is retryable. Missing/unwritable files instead explain **This note may have moved or is no longer writable. Your draft is still here.** Do not recreate a missing file. |
| Transport/uncertain outcome | **Save not confirmed.** — **Your draft is still here. Check the connection and try saving again.** Never say the disk was unchanged when that is unknown. A deliberate retry must retain the original revision fence; uncertainty never authorizes an overwrite or automatic replay. A stale retry follows the conflict state below. |
| External-change conflict | **This note has changed since you opened it.** — **Your draft is still here. Copy any changes you want to keep, then reload the saved note.** Keep textarea editable/selectable, but make Save unavailable with an associated reason. Offer **Reload saved note**; it opens the same explicit discard confirmation before replacing anything. No overwrite, force-save, silent rebase, merge UI or save-as. |
| Confirmed reload after conflict | Read the current saved note and replace the draft/base only after a successful read. On success return to rendered reading and announce **Saved note reloaded.** On read failure keep the draft and show **Couldn't reload this note. Your draft is still here.** An unresolved reload does not open an overwrite path. |

Content results group retained hits by filename/full path. Each matching physical line is one independent native link with visible **1-based line number** and literal snippets. No duplicate line for multiple possible alignments, score percentages, syntax rendering, inline media or new per-result ellipsis/context-menu behavior. Render all returned snippet windows in order, inserting explicit ellipses only for omitted source intervals. Each window's `positions` are relative to its literal `text`; `start`/`end` identify zero-based, end-exclusive UTF-16 source offsets. Every returned match position must remain visible, including dispersed matches across multiple windows. Use escaped React text nodes and `<mark>`, never highlighted HTML strings or Markdown rendering. Expand visual mark ranges to whole graphemes without changing the source string or interpreting UTF-16 indexes as code-point indexes. ### Pending, totals, limited results and incomplete coverage

Debounce input initially by about 200ms, with abort and generation fences as well. Neither a response nor a refresh selects a result or steals focus. Announce short settled counts politely, never filenames/snippets as a live-region transcript.

|---|---|

| Finished content search | **12 matching lines in 4 files.** Count physical lines, not files or snippet windows as interchangeable units. |
