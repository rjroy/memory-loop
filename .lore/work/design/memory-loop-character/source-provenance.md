# Memory Loop character board — sources and scope

This is a portable, static visual reference for `memory-loop-pxj.1`, not the application, a new approved identity, or permission to implement future features. The user authorized one four-mode board using existing brand references: Ground inspiring, Capture a blank slate, Think curious, Recall reflective. All example goals, notes and exchanges are authored illustrative content. The only quoted brand line, “A light offered. A path chosen.”, is identified as The Guide's line. No real vault, configuration, metrics, quotes, conversations or personal notes were read.

The proposed north star is **one familiar place, four different ways to arrive**. The board uses full, unaltered A.1 artwork to invite someone into Ground; no narrative illustration in Capture; a compact original A.5 signature alongside Think's invitation; and a small margin signature beside Recall's editorial reading surface. IM Fell English SC carries identity/invitations, Source Sans 3 the working interface, and Libre Baskerville reflective editorial passages. Light Capture/Recall surfaces and Horizon destination marks are visual proposals, not approved live-app changes or resolution of `memory-loop-ftj`. The parent decision `memory-loop-pxj` remains the place to agree direction.
